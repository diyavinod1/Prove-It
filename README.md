## 🎀 WHAT IS PROVE IT?

Prove It is a fun, shareable friendship quiz where people answer questions about **YOU** to find out how well they actually know you.

Create your own challenge, add personal questions, share your link, and let your friends compete for the highest score.

No AI. No personality-test essays. No 47-step onboarding.

Just friendship, competition, and the occasional *"BRO HOW DID YOU GET THAT WRONG?"*

## 🧠 WHY THIS PROJECT?

I wanted to build something people would genuinely want to use and share — not another project that exists solely to decorate a portfolio.

Prove It turns a simple, universally relatable question into a small social experience:

**"How well do my friends actually know me?"**

Behind the fun is a full-stack application involving interactive UI, challenge creation, shareable links, persistent data, and quiz scoring.

And the best part?

**It's live. People have used it. Real humans have entered the lore.** 🥹💖

Building a project is cool.

Building something that leaves your laptop and reaches real people? That's the real win.

## 🚀 RUN IT LOCALLY

<summary><b>👩‍💻 Click to set up Prove It on your machine</b></summary>

### Prerequisites

* Node.js and npm
* A Supabase project
* The environment variables required by the application

### Installation

```bash
# Install dependencies
npm install

# Create your local environment file
# Add the required Supabase configuration

# Start the development server
npm run dev
```

Open the local URL provided by Vite and you're ready to go.

### Environment setup 🔐

Configure the Supabase URL and public client key using the exact variable names expected by your project.

**Never commit service-role keys, database passwords, or other secrets.**
